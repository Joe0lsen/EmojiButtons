# Emoji Buttons 😀

## About

Emoji Buttons is a React Native app I built to keep my toddler busy. It keeps him busy for about 10mins&mdash;long enough for mom or dad to get something done, short enough to not get glued to the screen.

This React Native app was built using the Expo framework. As such, most of the code you'll see in this repository was generated by Expo. The meaningful code that I produced can be found in `app/index.js` (and `constants/styles.js` if interested).

## How To Start

### Local Development

1. `git clone https://github.com/Joe0lsen/EmojiButtons.git`

2. `cd EmojiButtons`

3. `npm intall`

4. `npx expo start` or
   `npx expo start --tunnel`

The terminal will then give you a clickable link to open the app in your default browser.

You can also use the Expo Go app to scan the QR code generated in the terminal, and try it out on your mobile device. If you are having trouble getting the app to work on your mobile device, the Expo Go app may not be able to find the app on your local network. In this case, try `npx expo start --tunnel`

### Android

The current Android build can be found here:
https://expo.dev/accounts/joe0lsen/projects/EmojiButtons/builds/8f4db61b-f767-4a92-b9b6-ce421fc868d5

Download it via your Android devices browser, give the prompted permissions, and run it like a normal app.

### iOS

As I have not built or tested for iOS, the way to run it on iOS is to use the Expo Go app. Follow the [Local Development](#local-development) steps above, then scan the QR code with the Expo Go app.
